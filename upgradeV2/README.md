# Artifacts

This folder contains project artifacts for analysis, visual mapping, and documentation.

## Subfolders

- `memory-map/` — Project memory maps and architecture summaries.
- `canvas/` — Visual canvas files representing current UI layouts and screens.
- `md/` — Markdown documentation migrated from the root `md/` folder.

## Purpose

Use this folder as the single source for working artifacts during design and implementation.

- Keep `memory-map/` for internal architectural notes and context.
- Keep `canvas/` for visual mockups and current app state artifacts.
- Keep `md/` for project documentation, plans, and design notes.
- Keep `progress.md` for phase status, completed work, and immediate next actions.

## Workflow

1. Read `upgradeV2/progress.md` first to see the current phase, completed phases, and next actions.
2. Read `upgradeV2/md/action-plan.md` for the detailed premium product roadmap and phase definitions.
3. Use `upgradeV2/memory-map/project-memory-map.md` for architecture context, current code status, and implementation notes.
4. Use `upgradeV2/canvas/action-plan.canvas` for the current UI artifact and visual reference.
5. After completing a phase or task, update `upgradeV2/progress.md` and add a short note in the relevant markdown artifact.
